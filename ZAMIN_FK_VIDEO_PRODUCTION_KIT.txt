1. THE PIPELINE IN ONE PICTURE
======================================================================
 Vote result + numbers (you)  ->  LEDGER.md (fund, fans, likes)
        |
        v
 Script (Uzbek, 5-6 beats, 35-45 s)         -> 0N_Episode_0N/script.md
        |
        v
 Narration voice per beat (ElevenLabs)      -> voice/01_hook.mp3 ... 06_outro.mp3
        |
        v
 Animation file (scenes, sprites, cards,    -> anim_ep0N.py
 counters, captions timed to the voice)
        |
        v
 Render: browser draws every frame (1080x1920, 30 fps) -> ffmpeg -> silent MP4
        |
        v
 Mix voice (+ optional whistle / crowd), loudness -14 LUFS -> exports/ZFK_EP0N_dayN.mp4 + .srt
        |
        v
 You watch on phone -> approve -> post to Instagram + TikTok -> write cutoff time

5. THE ANIMATION ENGINE (our own, free, no paid video service)
======================================================================
 Folder: tools/anim/
 - engine.html + engine.js: draws one frame at time t in a browser page 1080x1920.
 - render.js: steps time frame by frame (30 fps), screenshots each frame, pipes to ffmpeg.
 What it can do (used in every episode):
 - Backgrounds with slow zoom / pan / focus point / blur.
 - Sprites (characters) with entry moves: pop, fade, up, slideL, slideR, drop, peekR, stamp
   and idle moves: bob, hop, sway, shake, chew (goat), talk (goat speaking), pulse.
 - Labels = any HTML: title text, yellow "chips", cards (fund card, player cards with stats,
   VS match card), LED screen content, comment screenshots, "+ OBUNA BO'LING" button.
 - Number counters that roll up (fans, likes, fund).
 - Word-by-word captions synced to the voice, key words highlighted.
 Older simpler builder (stills + overlays only): tools/build_episode.py + render_overlays.js.
 Helper: tools/key_sprite.py = removes magenta/green background -> clean transparent sprite.

======================================================================
9. HOW A NEW VIDEO IS MADE (step by step)
======================================================================
 1. You send: winning comment + likes, Instagram + TikTok followers, total likes, post links.
 2. I update LEDGER.md (fund = previous + new likes x 15 000).
 3. I write script.md: HOOK (result) -> NEWS -> NUMBERS -> NEW PROBLEM -> ONE QUESTION -> OUTRO.
 4. I generate the voice lines (ElevenLabs), one file per beat.
 5. If a new character/place is needed: generate with Poyo (gpt-image-2.6-fixed, ~1.7 credits
    each), green/magenta background -> key_sprite.py -> transparent sprite.
 6. I copy the last anim_ep0N.py and change scenes, chips, cards, counters, captions.
 7. Quick check: render a few still frames (--frames 1,5,12) and look at them.
 8. Full render (~2-4 minutes) -> exports/ZFK_EP0N_dayN.mp4 + .srt + caption text.
 9. You review on the phone, then post. Also 1-2 story images if needed.
