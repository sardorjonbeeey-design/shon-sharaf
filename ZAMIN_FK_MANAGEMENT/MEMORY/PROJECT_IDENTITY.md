# Project Identity

Project: ZAMIN FK Management
Status: early concept and isolated prototype
Memory: independent written project memory

## What it is
An evolving football club management game. The player creates a virtual club, builds a squad, manages finances, develops virtual players, watches automatically simulated matches and competes in leagues. The immediate goal is to build and test a small playable foundation, then improve it through testing.

## What it is not
- Not the existing ZAMIN FK Telegram Mini App.
- Not the existing city, stadium, supporter portal, bot or roleplay economy.
- Not a directly controlled real-time football game in its initial direction.
- Not a real-world club membership or player recruitment database.
- Not a collectible-player-card trading game. “Player cards” means quality categories, not collectible artwork.

## Relationship to ZAMIN FK
The game uses the ZAMIN FK identity, but its game systems and memory remain distinct from the existing community and Mini App systems. A standalone website, mobile app or Telegram Mini App may be considered as an interface later; no interface integration is approved.

## Design approach
Start small, test mechanics, preserve flexibility, record owner decisions accurately, and never present proposals as approved facts.
